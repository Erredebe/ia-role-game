# Juego de Rol con IA

Este proyecto es un juego de rol interactivo impulsado por inteligencia artificial. Utilizamos LM Studio para gestionar la IA, permitiendo una experiencia narrativa dinámica.

## Descripción

El juego consiste en un chat donde la IA genera la historia del juego de rol. El usuario puede leer la narrativa generada y responder, influenciando el desarrollo de la trama.

## Características

- Narrativa generada por IA
- Interacción en tiempo real a través de chat
- Uso de LM Studio para el manejo de modelos de lenguaje

## Requisitos

- LM Studio instalado y configurado
- Un modelo de lenguaje compatible cargado en LM Studio

## Instalación

1. Clona este repositorio.
2. Instala las dependencias necesarias (si aplica).
3. Configura LM Studio con tu modelo preferido.

## Uso

1. Inicia LM Studio y carga el modelo.
2. Ejecuta la aplicación.
3. Comienza el chat y disfruta del juego de rol.
